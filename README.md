# LogiVoice AI — Автономный голосовой RAG-диспетчер

Интеллектуальная система диспетчеризации для водителей-экспедиторов логистических компаний. Сервис осуществляет сквозную обработку голосовых сообщений водителей, находит релевантные регламенты в векторной базе знаний и генерирует точные оперативные инструкции без обращения к внешним платным API.

---

## Архитектура пайплайна

1. Audio Input: Прием аудиозаписи запроса водителя (WAV/MP3).
2. STT (Speech-to-Text): Транскрибация речи моделью faster-whisper (medium, CUDA int8_float16, VAD-фильтрация фонового шума).
3. RAG (Retrieval-Augmented Generation):

* Векторизация запроса через легковесный русскоязычный энкодер cointegrated/rubert-tiny2.
* Семантический поиск топ-релевантных пунктов регламента в in-memory индексе FAISS.

4. LLM Inference: Генерация краткого диспетчерского ответа локальной моделью Llama 3.1:8B через Ollama (temperature=0.2, исключение галлюцинаций).
5. API Delivery: Формирование структурированного JSON-ответа с текстом, контекстом и метриками задержки через FastAPI.

---

## Стек технологий

* Backend & API: Python 3.10+, FastAPI, Uvicorn, Pydantic
* Распознавание речи: Faster-Whisper, CTranslate2, cuBLAS/cuDNN (CUDA acceleration)
* Векторный поиск (RAG): FAISS (CPU), Sentence-Transformers, Hugging Face Hub
* Языковая модель: Ollama, Llama 3.1:8B, AsyncOpenAI Client
* Инфраструктура: Docker, Docker Compose, Windows Batch Scripting

---

## Замеры производительности (Hardware: RTX 3060 Ti 8GB)

* STT (распознавание аудио 5–10 сек): ~1.5 – 3.5 сек.
* Семантический поиск (FAISS): менее 0.05 сек.
* Инференс LLM (прогретый контекст): ~1.5 – 2.5 сек.
* Общий сквозной Latency пайплайна: ~4.0 – 6.0 сек.

## Локальный запуск

1. Подготовка окружения
Убедитесь, что движок Ollama запущен и содержит целевую модель:
ollama run llama3.1:8b
2. Запуск сервера
Перейдите в директорию backend, активируйте окружение и запустите Uvicorn:
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
3. Интерактивная документация
После запуска интерактивный Swagger UI для тестирования эндпоинта /api/transcribe доступен по адресу:
[http://127.0.0.1:8000/docs](https://www.google.com/search?q=http://127.0.0.1:8000/docs&utm_source=gemini)

## Развертывание в Docker

Для сборки и запуска изолированного сервиса выполните команду из корневой директории:
docker compose up --build
